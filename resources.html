TB Toolkit Data

Export the structured data used by TB Toolkit for your own spreadsheets, analysis, clan tools, or custom projects. Choose the dataset and file format you want.

CSV · JSON · EXCEL
All TB Toolkit Data Downloads the complete public dataset.

Excel is best for browsing and analysis. CSV is broadly compatible with spreadsheets and databases. JSON preserves the native structured data for programming and web projects.

When All TB Toolkit Data is selected, CSV downloads as a ZIP containing one CSV file per dataset; Excel uses one worksheet per dataset.
