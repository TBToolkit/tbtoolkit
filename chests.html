Chest Data

Average rewards from Total Battle chests, based on compiled opening data.

How to read this table

Every value is the average amount received per chest. Actual drops vary from chest to chest, but larger samples should trend toward these averages. For example, an average of 2,290 Gold per Arachne chest means opening 100 similar chests would be expected to yield about 229,000 Gold over time.

Blank cells mean there is no compiled average for that reward in the current dataset.
